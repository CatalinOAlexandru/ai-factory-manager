# AI Factory Manager · concept demo

Concept demo, example data. Not a live product.

- `/demo/` is a clickable demo. Every machine, number and message in it is example data.
- Pages ask search engines not to index them (`robots.txt` and `noindex`).

This folder is static. There is no build step: GitHub Pages serves the files as they are.
